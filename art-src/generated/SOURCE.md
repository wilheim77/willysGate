# Arte generado por scripts (propio)

- Origen: dibujado píxel a píxel por `scripts/art/build-extra-art.ts` (tablones, andamios, remate de muro, rebordes, antorcha, brasero, sangre, chispa, polvo) con la paleta de 0x72 DungeonTileset II.
- `dirt_face` y `slag_face` son las caras de acantilado de Ninja Adventure (`TilesetRelief.png`, CC0) recoloreadas por luminancia a la paleta de 0x72.
- `wall_top_*` reutiliza las cuatro filas inferiores de `wall_top_mid` de 0x72 (CC0).
- Licencia: CC0 1.0 (obra propia del proyecto y derivados de material CC0).
- No se edita a mano: se regenera con `npm run art`. El `.txt` lista cada sprite como `nombre x y ancho alto`.
